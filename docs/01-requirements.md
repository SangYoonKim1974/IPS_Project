# 📋 01. 요구사항 정의서 및 4주 개발 로드맵 (WBS)

## 1. 시스템 권한 체계 (RBAC)
실제 기업 환경에 맞춰 3단계 권한으로 데이터를 통제합니다.
- **ADMIN (시스템 관리자):** 사원 계정 생성/비활성화, 부서/직급 관리, 전체 재고 및 결재 내역 열람
- **MANAGER (부서장/팀장):** 소속 부서원의 결재 문서 승인/반려, 부서 내 비품 불출 승인
- **USER (일반 사원):** 본인 정보 조회/수정, 전자결재 기안 및 진행 상태 확인, 비품/재고 사용 신청

## 2. 핵심 모듈별 상세 요구사항 (MVP + AI)

### 모듈 ① 사원 및 권한 관리 (`Users & Auth`)
- **로그인/로그아웃:** 사번 또는 이메일 기반 JWT 토큰 인증
- **사원 관리 (Admin):** 신규 입사자 등록, 부서(영업/개발/경영지원 등) 및 직급 배정, 퇴사자 계정 비활성화(Soft Delete)
- **권한 미들웨어:** API 호출 시 사용자 Role(`ADMIN`, `MANAGER`, `USER`) 검증

### 모듈 ② 전자결재 (`Approval`)
- **결재 기안 (User):** 휴가신청서, 지출결의서, 비품구매요청서 중 양식 선택 후 결재선(팀장/관리자) 지정하여 상신
- **결재 처리 (Manager/Admin):** 대기 중인 문서 조회 후 **승인(Approved)** 또는 **반려(Rejected)** 처리 (반려 시 사유 입력 필수)
- **상태 추적:** `대기(PENDING)` → `진행중(IN_PROGRESS)` → `최종승인(APPROVED)` / `반려(REJECTED)` 상태 관리

### 모듈 ③ 재고 및 자산 관리 (`Inventory & Assets`)
- **품목 등록 (Admin):** 소모품(재고 수량 관리)과 고정자산(노트북, 모니터 등 시리얼 번호 및 지급 대상자 관리) 구분 등록
- **입출고 관리:** 입고 시 재고 증가, 출고(불출) 시 재고 차감 (**재고 0 미만 출고 방지 트랜잭션 처리**)
- **안전 재고 알림:** 설정된 최소 수량 이하로 떨어질 경우 대시보드에 '발주 필요' 경고 표시

### 모듈 ④ 사내 업무 보조 AI (`AI Assistant`)
*외부 LLM API(Google Gemini API 또는 OpenAI API)를 백엔드에 연동하여 실무 생산성을 높입니다.*
- **AI 결재 문서 초안 및 요약기:**
  - 기안자가 핵심 키워드만 입력하면 격식 있는 결재 문서 본문 초안을 자동 생성
  - 결재자(팀장/관리자)가 상신된 문서를 열람할 때 **3줄 핵심 요약** 자동 제공
- **영수증 이미지 자동 인식 (OCR):**
  - 지출결의서 작성 시 영수증 이미지를 업로드하면 AI Vision 모델이 **상호명, 결제일자, 총 금액**을 JSON으로 추출하여 입력 폼에 자동 반영
